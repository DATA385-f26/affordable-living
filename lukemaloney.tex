\begin{enumerate}

\item
  Source Identity

  Source name

  The American Affordability Tracker

  Domain/topic

  Cost of living

  Source type

  Institutional data / Research dataset

  \begin{enumerate}
  \def\labelenumii{\arabic{enumii}.}
  \setcounter{enumii}{1}
  \tightlist
  \item
    Collection Context

    Collector/producer

    Urban Institute

    Original purpose

    A data tool funded by Urban Institute, which is a nonprofit research
    organization with the goal of equipping changemakers with evidence
    and solutions to improve lives and strengthen communities.

    Collection method

    Uses the Missouri Census Data Center's 2022 Geographic
    Correspondence Engine crosswalks to convert data from Public Use
    Microdata Areas (PUMAs), zip codes, and counties (depending on data
    source) to population-weighted averages by congressional districts.
    Also uses population-based weights to aggregate up to the state and
    national levels where needed.

    Record-creation event

    Updated as new indicators and more recent data becomes available.

    \begin{enumerate}
    \def\labelenumiii{\arabic{enumiii}.}
    \setcounter{enumiii}{2}
    \tightlist
    \item
      Observation and Scope

      Unit of observation

      One geographic area (a national average, state or congressional
      district) for a specific time period

      Population or objects represented

      U.S. households, U.S. consumers, and geographic regions

      Time period covered

      2017 - 2025 (varies by metric)

      Geographic area coverage

      United States

      \begin{enumerate}
      \def\labelenumiv{\arabic{enumiv}.}
      \setcounter{enumiv}{3}
      \tightlist
      \item
        Variables and Data Structure

        Main variables/fields

        Rent, home sale prices, gas prices, grocery prices, and average
        weekly earnings

        Data types included

        Numerical (dollar amounts, percentages, credit scores, etc.),
        text (dictionary definitions), time (months, quarters, years),
        and location (zip codes, counties, states, congressional
        districts)

        Direct measurements

        Average price per gallon of regular gas, average weekly earnings
        of all employees, average Vantage credit score

        Possible proxy variables

        Thrifty Food Plan market basket for a family of four is used as
        a stand in for general grocery costs.

        \begin{enumerate}
        \def\labelenumv{\arabic{enumv}.}
        \tightlist
        \item
          Documentation

          Documentation found

          Technical Appendix PDF, Data dictionary CSV, ID variables
          dictionary CSV

          Stated collection details

          All metrics are available at the national and state level.
          Data is provided by congressional district using fixed 119th
          Congress boundaries for all years. Data for some congressional
          districts may not be available.
        \end{enumerate}
      \end{enumerate}
    \end{enumerate}
  \end{enumerate}
\end{enumerate}
